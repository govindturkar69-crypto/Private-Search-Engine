# Product Requirements Document (PRD)

## Vision
A privacy-first, self-hosted search engine for discovering and searching crawled content.

## Features
1. **Search Interface** - Fast search box, ranked results, pagination
2. **Crawling System** - Lawful crawling, robots.txt compliance, rate limiting
3. **Admin Dashboard** - Crawl logs, manual triggers, statistics
4. **Privacy Controls** - No tracking, opt-in telemetry, data deletion

## Success Metrics
- Query latency: <1s (p95)
- Crawl speed: 100+ docs/minute
- Test coverage: >80%
- Zero vulnerabilities
